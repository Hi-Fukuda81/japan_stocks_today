# NG 表現と言い換え

台本・タイトル・概要欄の要約に、次の表現を **含めてはいけない**(部分一致で検出する)。
`validate.py` はこのファイルの「- `語`」の行を読み込んで検査する。語を追加するときは同じ書式で書く。

## 投資推奨・売買の示唆

- `買い時` → 使わない。事実だけを述べる
- `売り時` → 使わない
- `買い場` → 使わない
- `買うべき` → 使わない
- `売るべき` → 使わない
- `買い増し` → 使わない
- `押し目買い` → 使わない
- `損切り` → 使わない
- `利確` → 使わない
- `おすすめ` → 使わない
- `オススメ` → 使わない
- `お勧め` → 使わない
- `推奨` → 使わない
- `チャンス` → 使わない
- `狙い目` → 使わない
- `仕込み` → 使わない
- `注目銘柄` → 「大量保有報告書が出た銘柄」など、データの切り口で言う
- `目標株価` → 使わない
- `買収される` → 公開買付届出書が提出された、と事実で言う
- `株価は` → 株価の動きは data.json にないので触れない

## 価格予想・断定

- `上がりそう` → 使わない
- `下がりそう` → 使わない
- `上がる` → 過去形「上昇しました」で事実を述べる
- `下がる` → 過去形「下落しました」で事実を述べる
- `上昇するでしょう` → 使わない
- `下落するでしょう` → 使わない
- `期待できる` → 使わない
- `確実` → 使わない
- `間違いない` → 使わない
- `絶対` → 使わない
- `必ず` → 使わない

## 符号を記号的に言う表現

- `プラス` → 「上昇」「円安」など言葉で向きを言う
- `マイナス` → 「低下」「円高」など言葉で向きを言う

## 煽り表現

- `儲かる` → 使わない
- `儲け` → 使わない
- `爆上げ` → 「大きく上昇しました」
- `爆益` → 使わない
- `暴騰` → 「大きく上昇しました」
- `暴落` → 「大きく下落しました」
- `見逃せない` → 使わない
- `ヤバい` → 使わない
